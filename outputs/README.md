# Output files

This directory contains the outputs generated by MMLD tasks. The exact files depend on the command and selected options.

## Prepare

When `--output-dir` is omitted, the folder is named
`00_prepare_<data-type>_<input-stem>`, so different abundance workbooks do not
overwrite one another.

| File | Content |
|---|---|
| `input_abundance.xlsx` | Copy of the abundance workbook supplied to `prepare` |
| `input_causal_graph.xlsx` | Copy of the supplied causal graph; absent when the graph is inferred |
| `input_mpc_initial.xlsx` | MPC initial-state workbook, auto-detected as `initial.xlsx` beside the abundance input or supplied with `--mpc-initial` |
| `input_mpc_target.xlsx` | MPC target-state workbook, auto-detected as `target.xlsx` beside the abundance input or supplied with `--mpc-target` |
| `MMLD_processed_causal_graph.xlsx` | Processed graph with `edge_list`, `growth_rate`, and `self_interaction` sheets |
| `MMLD_model.pt` | Model file |
| `preprocessed_data.pkl` | Data preprocessing file |
| `causal_network.pdf` | Signed causal-network plot generated directly from the original input or inferred causal graph |

## Predict

| File | Content |
|---|---|
| `prediction_abundance_wide.xlsx` | True and predicted abundance by species in wide form |
| `prediction_abundance_long.xlsx` | Long-form true and predicted abundance |
| `prediction_summary.xlsx` | Subject-mean Pearson R and RMSE  values averaged; RMSE uses the original abundance scale |
| `prediction_metrics_by_subject.xlsx` | Pearson R and RMSE  values for each held-out subject |
| `pearson_r_by_subject_time.xlsx` | Pearson correlation by subject and time |
| `match_sample_selection.xlsx` | Similar-subject selection for `--mode match` |

## Classify

| File | Content |
|---|---|
| `classification_results.xlsx` | Timepoint-level true labels, predicted labels, probabilities, and fold IDs |
| `classification_roc_curves.pdf` | One-vs-rest ROC curves for all classes |
| `MMLD_one_step_abundance_raw.xlsx` | One-step predictions in the original scale |
| `MMLD_one_step_abundance_scaled.xlsx` | One-step predictions in model scale |
| `classification_summary.xlsx` | Mean AUC across the selected subject-level split(s) |
| `MMLD_model.pt` | Model file |

## Driver and MPC

| File | Content |
|---|---|
| `minimum_driver_species_sets.xlsx` | All minimum driver sets |
| `MPC_abundance_results.xlsx` | Original, controlled, and target abundance in wide form |
| `MPC_metrics.xlsx` | Per-subject, real start time, and step Pearson R and RMSE metrics |
| `MPC_best_intervention_by_subject.xlsx` | Best intervention start and step per subject |

## Keystone

| File | Content |
|---|---|
| `keystone_knockout_ranking.xlsx` | Final-epoch knockout ranking |
| `MMLD_model.pt` | Model file |

## Change-point detection

| File | Content |
|---|---|
| `adjacent_R_changepoint_results.xlsx` | Per-timepoint R/RMSE value, subject-level and group-level adjacent tests, retained graph edges, and configuration |
| `subject_<id>_adjacent_R_change.pdf` | Subject-specific Pearson R and RMSE  values curves with significant adjacent comparisons |
| `mean_adjacent_R_change.pdf` | Cross-subject mean Pearson R and RMSE  values curves |
| `mean_R_boxplot.pdf` | Pearson R value distributions over real sampling times |
| `run_configuration.json` | Analysis parameters |
